# 🎂 Sabiya Birthday — Interactive Digital Surprise

Birthday surprise for **Sabiya — 09 November**.

### Features
- 🔐 DOB unlock screen
- ✨ Premium animated/glow design
- 💌 Typewriter birthday letter
- 🎁 Interactive gifts
- 🎂 Candle cake
- 🎆 Grand finale
- 📱 Mobile friendly

### GitHub Pages
Upload `index.html`, `style.css`, and `script.js` to a GitHub repository, then enable **Settings → Pages → Deploy from branch → main → /(root)**.

### Change the unlock date
In `script.js`, change `d==='09'&&m==='11'`.

> This is a front-end surprise lock, not a secure password system.
